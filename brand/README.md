# Папка для логотипа

Положите сюда файл **`logo.png`** — свой логотип на прозрачном или белом фоне,
квадратный, желательно не меньше 512×512.

После этого выполните в корне проекта:

```bash
node tools/make-icons.mjs
```

Скрипт соберёт из него `icons/app-icon.png` — иконку, которую видно на
домашнем экране телефона: впишет логотип в квадрат 512×512, оставит по краям
поле 14% (чтобы Android не обрезал углы круглой маской) и зальёт фон белым.

**Если node не установлен** — скрипт не нужен. Сделайте квадратный PNG
512×512 любым способом и просто положите его вместо `icons/app-icon.png`,
сохранив имя файла. Подробная пошаговая инструкция — в README проекта,
раздел «Своя иконка на домашнем экране».

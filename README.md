# Discovery Bank — макет мобильного банка

Макет банковского приложения для тестового задания: экран входа, дашборд,
история операций за пять месяцев и заказ выписки по счёту. Интерфейс на
английском. Ванильный HTML/CSS/JS, без сборки и зависимостей.

**Доступ:** логин `+27662582832`, пароль `0605`.

Клиент — Charne Puren, счёт Discovery Gold Transaction Account 14902470882,
остаток на 14 августа 2026 — R 284 647.22.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно просто открыть `index.html` двойным кликом. Собранная версия одним
файлом — `dist/discovery-bank.html`.

```bash
node tools/build-artifact.mjs   # пересобрать dist/
node tools/make-icons.mjs       # собрать иконку из brand/logo.png (нужен playwright)
```

### Заказ выписки

Форма собирает счёт, период, состав документа (реквизиты счёта, история
транзакций, сводка по категориям), формат (PDF/CSV) и способ доставки.
После отправки заявка ~2,5 секунды висит в статусе «Processing», затем
становится «Ready» — открывается документ.

Периоды:

- **Last month** — прошлый полный календарный месяц;
- **3 months** — три полных календарных месяца, текущий неполный не берётся
  (на 14 августа это май, июнь, июль);
- **Custom** — свои даты: «From» и «To» открывают календарь с месячной
  сеткой. Даты вне истории счёта недоступны, начало не может оказаться
  позже конца.

По умолчанию выписка остаётся **в приложении**. Кнопка **Email** на готовом
документе — обычная ссылка `mailto:` с уже заполненными темой и телом письма
(счёт, период, обороты, остатки), поэтому на телефоне открывается системный
выбор почтового приложения. Прикрепить сам PDF ссылка не может — файл
сохраняется кнопкой «Print / PDF» и прикладывается вручную.

**Бланк выписки повторяет форму Discovery:** знак с надписью справа сверху,
заголовок «<название счёта> statement», строка TAX INVOICE, адрес клиента и
параметры выписки (номер, дата, период, овердрафт, минимальный платёж) в две
колонки, градиентная линейка, блок «Your account summary» с opening/closing
balance, таблица «Transaction timeline» (Date · Card no. · Type · Details ·
Amount) со строками Opening balance и Closing balance, строка Total VAT с
пометкой платных операций, список держателей карт и подвал с реквизитами
банка. Суммы в документе — в формате выписки: разряды через пробел, минус
перед `R` (`- R13 329.60`).

Бланк набран **Open Sans** в двух начертаниях — regular и bold. Шрифт лежит
в репозитории (`assets/fonts/open-sans.woff2`, вариативная latin-версия,
Apache 2.0), поэтому документ выглядит одинаково офлайн, на хостинге и в
однофайловой сборке — туда шрифт вшивается base64. Остальное приложение
остаётся на системном шрифте.

Ограничения на количество выписок нет: кнопка «Order statement» работает
всегда. Цифра бесплатных выписок в месяц — константа `FREE_STATEMENTS`
в `assets/app.js`, сейчас 15, и она только показывается в форме.

На узком экране таблица прокручивается вбок внутри своего блока, при печати
разворачивается целиком. Кнопка «Print / PDF» использует системную печать
(в CSS есть отдельные правила `@media print`).

## Дизайн

Механика снята со скринов Discovery, а не скопирована картинкой:

- **Градиентная линейка** (`--rule`, маджента → фиолетовый → синий) под шапкой
  и над таб-баром — главный опознавательный элемент.
- **Два носителя цвета** на экран: маджента (активная навигация, иконки строк,
  кромка кружков операций) и тёмно-синий (кнопки, ссылки, дуги колец). Красный
  — только на сумме списания, это функциональная семантика.
- **Лента операций** собрана по эталону: заголовок дня обычным текстом без
  линейки, строки разделяет воздух, кружок иконки — тонкая кромка мадженты,
  мета идёт столбиком (тип / счета / категория), минус стоит **после** суммы.
- **Тени слоями** с разной прозрачностью и радиусом вместо одной «коробочной».
- **Типографика**: явные size/line-height/letter-spacing у каждого стиля, вес
  падает с ростом кегля, вторичный текст — отдельная краска, а не альфа.
- **Панель Vitality Money** — отдельная бронзовая сцена с источником света в
  левом верхнем углу; белые подкарточки внутри.
- **Статус-бар** рисуется только в десктопной рамке телефона. На самом
  телефоне и в установленном приложении он скрыт, чтобы не дублировать
  системный ряд времени, сети и батареи.
- Переходы между экранами: push/pop 300 мс на `cubic-bezier(.32,.72,0,1)`,
  шиты снизу, тосты как в референсе. Всё уважает `prefers-reduced-motion`.

Ширина макета — 402 px в рамке телефона на десктопе, на экранах уже 560 px
разворачивается во весь экран.

## Установка на домашний экран телефона

Макет собран как PWA: `manifest.webmanifest`, иконка `icons/app-icon.png`,
мета-теги `apple-*` в `index.html`. Запущенный с домашнего экрана, он
открывается без адресной строки, а рамка телефона и фальшивый статус-бар
скрываются (`@media (display-mode:standalone)`).

Нужен HTTPS-адрес. Проще всего — GitHub Pages: **Settings → Pages → Source:
Deploy from a branch → Branch: `claude/banking-app-mockup-83c9p3` / `/ (root)`**.
Через минуту макет будет на `https://<user>.github.io/bankapp/`.

Ярлык подписывается как **Discovery Bank** — Android берёт подпись из
`short_name` в манифесте.

- **Android (Chrome):** открыть адрес → ⋮ → *Add to Home screen* → *Install*.
- **Android (Samsung Internet):** ☰ → *Add page to* → *Home screen*.
- **iOS (Safari):** открыть адрес → «Поделиться» → *Add to Home Screen*.
  Обязательно Safari: другие браузеры на iOS ставят обычный ярлык.

## Своя иконка на домашнем экране

Иконку задаёт **один файл — `icons/app-icon.png`**. Что на нём нарисовано, то
и появится на телефоне. Ничего перекомпилировать не нужно: заменили файл,
обновили страницу на телефоне, переставили ярлык.

Требования к файлу: **квадрат 512×512, PNG, непрозрачный фон** (на прозрачном
iOS подставит чёрный), логотип не в край — оставьте вокруг поле примерно 15%,
иначе Android обрежет углы круглой маской.

Способ 1 — вручную, ничего ставить не надо (macOS Preview):

1. Откройте свой PNG двойным кликом — он откроется в «Просмотре».
2. Меню **Инструменты → Настроить размер…**
3. Снимите галочку **«Сохранять пропорции»**, впишите ширину `512` и высоту
   `512`, единицы — пиксели. **ОК**.
4. Меню **Файл → Экспортировать…**, формат **PNG**, имя `app-icon`, сохранить.
5. Положите получившийся `app-icon.png` в папку `icons/` проекта, заменив
   старый файл. Имя должно остаться ровно `app-icon.png`.
6. Залейте изменения на хостинг (пуш в ветку, если сайт на GitHub Pages).
7. На телефоне удалите старый ярлык, откройте сайт заново и добавьте его на
   домашний экран ещё раз — иконка кэшируется, поэтому старый ярлык сам не
   обновится.

Если фон логотипа прозрачный, перед шагом 4 подложите белый квадрат: проще
всего в Figma — фрейм 512×512 с белой заливкой, логотип по центру на ~72%
ширины, **Export → PNG → 1x**.

Способ 2 — скриптом, если установлен node:

1. Положите логотип как `brand/logo.png` (любой размер, можно с прозрачностью).
2. Выполните `node tools/make-icons.mjs`.
3. Скрипт сам впишет его в квадрат, добавит поля и запишет `icons/app-icon.png`.

## Как поменять бренд под себя

Название банка, реквизиты и данные клиента — две константы в начале
`assets/data.js`: `BANK` и `USER`. Счета и балансы — массив `ACCOUNTS` там же.

Цвета лежат в `:root` в `assets/styles.css`: `--magenta`, `--navy`, `--rule`
(градиентная линейка), `--bronze-1..3` (панель Vitality Money).

Знак **внутри интерфейса** живёт в `assets/icons.js` в трёх вариантах
(viewBox 24×24, цвет наследуется от `currentColor`):

| Файл или константа | Где используется |
|---|---|
| `assets/brand/logo-card.png` | пластик карты: знак слева сверху и по центру |
| `assets/brand/logo-statement.png` | шапка бланка выписки |
| `assets/brand/logo-seal.png` | гильошированный знак в подвале выписки |
| `icons/app-icon.png` | иконка на домашнем экране |
| `MARK_SOLID` в `assets/icons.js` | тосты и печать в подвале выписки |

Логотипы на карте и в выписке — из присланного брендбука: одноцветные PNG
с прозрачным фоном (палитровые, по 24–30 КБ). В однофайловую сборку они
вшиваются base64. Чтобы заменить — положите новые PNG под теми же именами
в `assets/brand/`.

Иконка **на домашнем экране** живёт отдельно — см. раздел выше. На экране
входа логотипа нет: в референсном приложении там только заголовок и поля.

## Структура

```
index.html                 каркас: рамка телефона, шапка, таб-бар, слои шита и тостов
manifest.webmanifest       манифест PWA для установки на домашний экран
icons/app-icon.png         иконка на домашнем экране (512×512, заменяется вручную)
brand/                     сюда кладётся logo.png для сборки иконки скриптом
assets/styles.css          токены, типографическая шкала, компоненты, печать
assets/icons.js            линейные иконки 24×24 и три варианта знака
assets/fonts/              Open Sans для бланка выписки (Apache 2.0)
assets/data.js             банк, клиент, счета, генератор проводок, срезы для виджетов
assets/app.js              состояние, роутер с переходами, экраны, действия
tools/build-artifact.mjs   сборка в один самодостаточный HTML
tools/make-icons.mjs       сборка icons/app-icon.png из brand/logo.png
```

## Оговорка

Это **макет для тестового задания**, а не рабочее приложение и не продукт
Discovery Bank. Платежи не проводятся, авторизация фиктивная, все данные
клиента и суммы — из учебной выписки. Знак в `MARK` — нарисованное приближение,
официальные брендовые ассеты в репозитории не используются.

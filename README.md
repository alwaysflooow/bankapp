# Meridian Bank — макет мобильного банка

Интерактивный макет банковского приложения по мотивам Discovery Bank: экран
входа, дашборд, история операций за несколько месяцев и заказ выписки по счёту.
Ванильный HTML/CSS/JS, без сборки и зависимостей.

**Демо-доступ:** логин `thandi`, пароль `demo1234`.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно просто открыть `index.html` двойным кликом — файловый протокол тоже
работает. Собранная версия одним файлом: `dist/meridian-bank.html`.

```bash
node tools/build-artifact.mjs   # пересобрать dist/
```

## Что внутри

| Экран | Что делает |
|---|---|
| **Вход** | Валидация полей, показ пароля, тост-ошибки, сессия в `localStorage`. Выход — из «Ещё» с подтверждением. |
| **Дашборд** | Имя и фамилия клиента, карусель счетов с балансами (портфель + 3 счёта), скрытие сумм «глазом», панель Momentum Money с кольцами привычек и донат-анализатором бюджета, последние операции. |
| **Счета** | Список счетов, детальная карточка: арт карты, баланс, реквизиты, действия, операции по счёту. |
| **Операции** | История за 4 месяца: поиск, фильтры по месяцу и счёту, сводка приход/расход, группировка по дням, шит с деталями операции. |
| **Карты** | Карта крупно, заморозка/разморозка, список карт, настройки безопасности. |
| **Ещё** | Разделы как в референсе, вход в хранилище документов, выход из приложения. |
| **Выписки** | Заказ выписки (счёт, период, состав, формат, доставка), список заявок со статусом, готовый документ. |

### Заказ выписки

Форма собирает счёт, период (прошлый месяц / 3 месяца / произвольный),
состав документа (реквизиты счёта, история транзакций, сводка по категориям),
формат (PDF/CSV) и способ доставки. После отправки заявка ~2,5 секунды висит в
статусе «Готовится», затем становится «Готова» — открывается сам документ:
шапка банка, данные клиента и счёта, таблица проводок с остатком после каждой,
итоги за период и разбивка списаний по категориям. Кнопка «Печать / PDF»
использует системную печать (в CSS есть отдельные правила `@media print`).

## Данные

`assets/data.js` генерирует историю детерминированно (LCG с фиксированным
seed), поэтому при каждой загрузке она одинаковая. Важное свойство: **балансы
не заданы руками** — они считаются из проводок, начиная с остатка на
30.04.2026. Поэтому выписка сходится с дашбордом: остаток на начало периода
плюс обороты равен остатку на конец и текущему балансу счёта.

Проценты по сберегательному счёту начисляются от фактического остатка на конец
месяца, погашение кредитной карты равно её обороту за предыдущий месяц,
переводы между своими счетами создают парные проводки. Бюджет в анализаторе
выводится из средних расходов за завершённые месяцы, внутренние переводы в
расход не попадают.

Текущая дата макета зафиксирована — 13 августа 2026 (`DB.TODAY`).

## Дизайн

Механика снята со скринов Discovery, а не скопирована картинкой:

- **Градиентная линейка** (`--rule`, маджента → фиолетовый → синий) под шапкой
  и над таб-баром — главный опознавательный элемент.
- **Два носителя цвета** на экран: маджента (активная навигация, иконки строк)
  и тёмно-синий (кнопки, ссылки, дуги колец). Зелёный — только на сумме
  поступления, это функциональная семантика, а не третий акцент.
- **Тени слоями** с разной прозрачностью и радиусом вместо одной «коробочной»:
  у света нет резкой кромки.
- **Разделители-hairline** с отступом под иконку, как в списке «More».
- **Типографика**: явные size/line-height/letter-spacing у каждого стиля, вес
  падает с ростом кегля (баланс 30/600, строка списка 16/450), вторичный текст
  — отдельная краска, а не альфа. Капса с трекингом нет нигде.
- **Панель Momentum Money** — отдельная бронзовая сцена с источником света в
  левом верхнем углу; белые подкарточки внутри.
- Переходы между экранами: push/pop 300 мс на `cubic-bezier(.32,.72,0,1)`,
  шиты снизу, тосты как в референсе. Всё уважает `prefers-reduced-motion`.

Ширина макета — 402 px в рамке телефона на десктопе, на экранах уже 560 px
разворачивается во весь экран.

## Оговорка

**Meridian Bank — вымышленный банк.** Референсом служил дизайн Discovery Bank,
но название, логотип, реквизиты, клиент и все суммы придуманы; торговые марки
Discovery не используются. Название банка и данные клиента меняются в одном
месте — константы `BANK` и `USER` в начале `assets/data.js`.

## Структура

```
index.html                 каркас: рамка телефона, шапка, таб-бар, слои шита и тостов
assets/styles.css          токены, типографическая шкала, компоненты, печать
assets/icons.js            линейные иконки 24×24 (currentColor)
assets/data.js             банк, клиент, счета, генератор проводок, срезы для виджетов
assets/app.js              состояние, роутер с переходами, экраны, действия
tools/build-artifact.mjs   сборка в один самодостаточный HTML
```

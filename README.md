# Meridian Bank — макет мобильного банка

Интерактивный макет банковского приложения по мотивам Discovery Bank: экран
входа, дашборд, история операций за несколько месяцев и заказ выписки по счёту.
Интерфейс на английском. Ванильный HTML/CSS/JS, без сборки и зависимостей.

**Демо-доступ:** логин `thandi`, пароль `demo1234`.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Можно просто открыть `index.html` двойным кликом. Собранная версия одним
файлом — `dist/meridian-bank.html`.

```bash
node tools/build-artifact.mjs   # пересобрать dist/
node tools/make-icons.mjs       # перерисовать иконки приложения (нужен playwright)
```

## Что внутри

| Экран | Что делает |
|---|---|
| **Log in** | Валидация полей, показ пароля, тост-ошибки, сессия в `localStorage`. Выход — из «More» с подтверждением. |
| **Home** | Имя и фамилия клиента, карусель счетов с балансами, скрытие сумм «глазом», панель Momentum Money с кольцами привычек и донат-анализатором бюджета, последние операции. |
| **Accounts** | Список счетов, детальная карточка: арт карты, баланс, реквизиты, действия, операции по счёту. |
| **Transact** | История за 4 месяца: поиск, фильтры по месяцу и счёту, сводка Money in / Money out, группировка по дням, шит с деталями операции. |
| **Cards** | Карта крупно, заморозка/разморозка, список карт, настройки безопасности. |
| **More** | Разделы как в референсе, вход в хранилище документов, выход из приложения. |
| **Statements** | Заказ выписки (счёт, период, состав, формат, доставка), список заявок со статусом, готовый документ. |

### Заказ выписки

Форма собирает счёт, период (Last month / 3 months / Custom), состав документа
(реквизиты счёта, история транзакций, сводка по категориям), формат (PDF/CSV) и
способ доставки. После отправки заявка ~2,5 секунды висит в статусе
«Processing», затем становится «Ready» — открывается сам документ: шапка банка,
данные клиента и счёта, таблица проводок с остатком после каждой, итоги за
период и разбивка списаний по категориям. Кнопка «Print / PDF» использует
системную печать (в CSS есть отдельные правила `@media print`).

## Данные

`assets/data.js` генерирует историю детерминированно (LCG с фиксированным
seed), поэтому при каждой загрузке она одинаковая. Важное свойство: **балансы
не заданы руками** — они считаются из проводок, начиная с остатка на
30.04.2026. Поэтому выписка сходится с дашбордом: остаток на начало периода
плюс обороты равен остатку на конец и текущему балансу счёта.

Общий баланс портфеля зафиксирован константой `TARGET_PORTFOLIO`
(сейчас `284647.22`). Опорный остаток сберегательного счёта подбирается
итерациями под эту цифру, поэтому проводки и выписка остаются согласованными.

Проценты по сберегательному счёту начисляются от фактического остатка на конец
месяца, погашение кредитной карты равно её обороту за предыдущий месяц,
переводы между своими счетами создают парные проводки. Бюджет в анализаторе
выводится из средних расходов за завершённые месяцы, внутренние переводы в
расход не попадают.

Текущая дата макета зафиксирована — 13 августа 2026 (`DB.TODAY`).

## Дизайн

Механика снята со скринов Discovery, а не скопирована картинкой:

- **Градиентная линейка** (`--rule`, маджента → фиолетовый → синий) под шапкой
  и над таб-баром — главный опознавательный элемент.
- **Два носителя цвета** на экран: маджента (активная навигация, иконки строк,
  кромка кружков операций) и тёмно-синий (кнопки, ссылки, дуги колец). Красный
  — только на сумме списания, это функциональная семантика.
- **Лента операций** собрана по эталону: заголовок дня обычным текстом без
  линейки, строки разделяет воздух, кружок иконки — тонкая кромка мадженты,
  мета идёт столбиком (тип / счета / категория), минус стоит **после** суммы.
- **Тени слоями** с разной прозрачностью и радиусом вместо одной «коробочной».
- **Типографика**: явные size/line-height/letter-spacing у каждого стиля, вес
  падает с ростом кегля, вторичный текст — отдельная краска, а не альфа.
- **Панель Momentum Money** — отдельная бронзовая сцена с источником света в
  левом верхнем углу; белые подкарточки внутри.
- Переходы между экранами: push/pop 300 мс на `cubic-bezier(.32,.72,0,1)`,
  шиты снизу, тосты как в референсе. Всё уважает `prefers-reduced-motion`.

Ширина макета — 402 px в рамке телефона на десктопе, на экранах уже 560 px
разворачивается во весь экран.

## Установка на домашний экран телефона

Макет собран как PWA: `manifest.webmanifest`, иконки в `icons/`, мета-теги
`apple-*` в `index.html`. Запущенный с домашнего экрана, он открывается без
адресной строки, а рамка телефона и фальшивый статус-бар скрываются
(`@media (display-mode:standalone)`).

Нужен HTTPS-адрес. Проще всего — GitHub Pages: **Settings → Pages → Source:
Deploy from a branch → Branch: `claude/banking-app-mockup-83c9p3` / `/ (root)`**.
Через минуту макет будет на `https://<user>.github.io/bankapp/`.

- **Android (Chrome):** открыть адрес → ⋮ → *Add to Home screen* → *Install*.
- **Android (Samsung Internet):** ☰ → *Add page to* → *Home screen*.
- **iOS (Safari):** открыть адрес → «Поделиться» → *Add to Home Screen*.
  Обязательно Safari: другие браузеры на iOS ставят обычный ярлык.

## Как поменять бренд под себя

Название банка, реквизиты и данные клиента — две константы в начале
`assets/data.js`: `BANK` и `USER`. Счета и балансы — массив `ACCOUNTS` там же.

Цвета лежат в `:root` в `assets/styles.css`: `--magenta`, `--navy`, `--rule`
(градиентная линейка), `--bronze-1..3` (панель Momentum Money).

Логотип — SVG-путь в `assets/icons.js`, константа `MARK` (viewBox 24×24,
только контуры, цвет наследуется от `currentColor`). Экспорт из Figma:
выделить знак → *Export → SVG* → открыть файл → скопировать содержимое
`<svg>` в `MARK`. Если знак заливкой, а не контуром, добавьте ему
`fill="currentColor" stroke="none"` прямо в пути.

## Структура

```
index.html                 каркас: рамка телефона, шапка, таб-бар, слои шита и тостов
manifest.webmanifest       манифест PWA для установки на домашний экран
icons/                     иконки приложения (180/192/512 + maskable)
assets/styles.css          токены, типографическая шкала, компоненты, печать
assets/icons.js            линейные иконки 24×24 (currentColor)
assets/data.js             банк, клиент, счета, генератор проводок, срезы для виджетов
assets/app.js              состояние, роутер с переходами, экраны, действия
tools/build-artifact.mjs   сборка в один самодостаточный HTML
tools/make-icons.mjs       генерация PNG-иконок из фирменного знака
```
